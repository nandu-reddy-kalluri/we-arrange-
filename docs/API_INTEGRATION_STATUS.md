## 2. F-01 Security Remediation Verification

  - Inactive/suspended/pending admins denied via `NOT EXISTS (... a.status <> 'active'::public.admin_status_enum)`.
  - Users with `roles.role_name = 'admin'` without an active `public.admins` row are denied (`lower(r.role_name) = 'concierge'` only).
  - Active concierges retain concierge permissions without admin elevation.
