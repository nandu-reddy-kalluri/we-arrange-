# ADR 002: Hyderabad-Only MVP Boundary

## Status
Accepted

## Context
YMWA aims to stand out by providing accurate, manually collected quotes and negotiations instead of automated web scraped catalog listings. 

## Decision
- Limit the Phase 1 MVP coverage area exclusively to Hyderabad, Telangana.
- Focus on Hyderabad's elite venues (Banjara Hills, Jubilee Hills, Hitec City, Shamshabad heritage locations).

## Implications
- Allows the concierge team to personally call, audit availability, and negotiate custom pricing packages.
- Keeps database records small and highly accurate.
- Establishes a scaling template before expanding to other metropolitan markets.
