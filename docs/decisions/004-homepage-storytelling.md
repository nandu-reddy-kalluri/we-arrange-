# ADR 004: Homepage Storytelling Sequence

## Status
Accepted

## Context
A premium platform must lead the customer through a logical narrative, answering key value questions sequentially rather than dumping tables of features.

## Decision
Configure the home page sections as a unified journey path:
1. **DREAM:** Hero planner inputs selection & match count preview.
2. **PLAN:** Concierge value mapping, coordinator profiles highlights.
3. **COMPARE:** Story comparisons slides & quotes compilation steps.
4. **CHOOSE:** Featured list grids (venues, categories, websites).
5. **CELEBRATE:** Actionable planning invitation CTAs.

## Implications
- Establishes clear landing layout boundaries for developers.
- Improves conversion ratios.
- Helps user contextualize the YMWA business model instantly.
