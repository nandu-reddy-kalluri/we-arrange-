# ADR 003: Human Concierge Business Flow

## Status
Accepted

## Context
Standard directories create high friction for high-end wedding shoppers by listing unverified pricing, leading to endless call spam.

## Decision
- Instead of showing static database results, YMWA acts as an intermediary.
- A dedicated coordinator personally collects, reviews, and maps multiple bidded options.
- The UI must focus on conveying trust in this coordination desk.

## Implications
- Eliminates spam calls for the customer.
- Maximizes quote accuracy and contract success ratios.
- Requires admin portal tools to assemble and format comparisons manually for users.
