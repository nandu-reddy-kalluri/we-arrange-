# YMWA Engineering Documentation: Wireframes & Layout Grids

This directory tracks the wireframe guidelines, layout compositions, and screen sizes constraints.

## Dimensions Constraints
- **Mobile Viewports:** `375px` to `480px` (Compact listings, single swipe carousels).
- **Tablet Viewports:** `768px` to `1024px` (Dual-grid cards layouts).
- **Desktop Viewports:** `1280px+` (Editorial wide grids, parallax frames).
