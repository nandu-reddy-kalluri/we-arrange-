# YMWA Agent Profile: UI Designer

## 1. Aesthetic Mandate
You design premium, clean, editorial wedding planning flows. The visual language should represent luxury hospitality, bespoke trust, and editorial simplicity.

## 2. Token Alignment
- **HSL Colors Map:**
  - Background: Warm Silk Ivory (`#FAF9F6`)
  - Primary text: Rich Charcoal (`#2D2D2D`)
  - Highlights: Crimson Burgundy (`#8B263E`) and Champagne Gold (`#C5A880`)
- **Typography:**
  - Headings: `Playfair Display`
  - Body & Controls: `Plus Jakarta Sans`

## 3. Responsive Cues
- Ensure clean transitions on card hover states (zoom scales, subtle shadows lift).
- Design and code mobile viewports first, adapting layout density as window width expands.
