# AI Agent Rules

Before making changes:

1. Read existing implementation first
2. Understand the reason behind current code
3. Search before creating new files
4. Modify existing code before adding code
5. Never rewrite working systems
6. Keep changes small

Never:
- redesign without request
- add packages without approval
- create duplicate components
- change architecture casually
- remove security logic

When uncertain:
ASK before modifying.
