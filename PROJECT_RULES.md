# YouMarriageWeArrange Project Rules

This document serves as the absolute visual and architectural source of truth for all AI and developer contributions to the YouMarriageWeArrange repository.

## Product Type

Premium Wedding Concierge Platform

**Strictly NOT:**
- A simple WeddingWire Clone
- A simple WedMeGood Clone
- A raw, automated Venue Directory

---

## Core Workflow

User submits search parameters and requirements
↓
Dedicated Concierge Specialists contact venues directly
↓
Specialists collect and negotiate custom packages and quotations
↓
User receives a clean, side-by-side comparison sheet
↓
User reviews comparison matrices and chooses the best option

---

## MVP Scope

- **Location Focus:** Hyderabad, Telangana Only (heritage palaces, luxury resorts, elite five-star banquets).

---

## Design Philosophy

- **Mobile First:** Primary target audience accesses YMWA via mobile. Build, review, and test mobile layouts first.
- **Desktop Enhanced:** Desktop is an incremental enhancement layer, leveraging wider visual storytelling canvas.
- **Editorial:** Use whitespace, clean serif layouts, and elegant serif headings.
- **Luxury Hospitality:** Focus on bespoke trust building and direct human concierge matching.
- **Human-Centered:** Clean, premium, and trustworthy interfaces.

---

## Animation Philosophy

- **Subtle & Purposeful:** Micro-interactions, smooth hover transitions, and performance-first fade/slide transforms.
- **Strictly Avoid:**
  - Floating Hearts
  - Confetti overlays
  - Fireworks animations
  - Heavy GPU-intensive particle engines
  - Excessive / unreadable Glassmorphism overlays

---

## UI Principles

Every page section and view must answer the following questions for the customer:
1. *Why trust us?*
2. *How does this work?*
3. *Why is this easier?*
4. *What happens next?*

---

## Homepage Journey Stage Mapping

1. **DREAM:** Hero section and requirements selection.
2. **PLAN:** Concierge value presentation.
3. **COMPARE:** Quotation collection steps and comparison preview.
4. **CHOOSE:** Featured venues, vendors categories, website builders.
5. **CELEBRATE:** Actionable final CTAs to submit planning requests.
